PhD thesis on synchronised neural responses to speech and speech sounds. This thesis was submitted in 2019 and contains small errors, some of which have been corrected formally since then. Contains original idea of performing computational predictive models of stimulus acquisition and encoding, and their stability analysis, with an initial guess that these are unstable and not bistable (for phoneme encoding). See "Next-generation neural mass models reproduce features of speech processing
Andrew Shannon, David Barton, Martin Homer, Conor J Houghton" which is inspired by this work and describes a model with pitchfork bifurcations determined by harsh and soft sounds only.
